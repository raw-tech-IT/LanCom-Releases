## LANCOM — Next Gen LAN Messenger

Message your team and share files directly over your local network with LANCOM for Windows and Android.

### Highlights

- Direct Windows–Android messaging and encrypted file transfers.
- Active users, availability, profile pictures and status notes.
- File requests and transfer progress inside conversations.
- Accept, decline, cancel and open-file controls.
- Windows offline outgoing messages and pending file offers that are delivered when both devices are reachable.
- Windows encrypted history and password-protected backup/restore.
- Safe numbered download names, improved notifications, themes and drag-and-drop feedback.
- Updated About credits and a compact `v5 rc86` Windows title label.

### Downloads

| Platform | File | Requirements |
| --- | --- | --- |
| Windows | `LANCOM-Setup-5.0.0-rc86-x64.exe` | Windows 10/11, x64 |
| Android | `LANCOM-Android-1.2.4.apk` | Android 8.0 or later |

Install LANCOM, connect your devices to the same local network, and open **Active Users** to start a conversation. Notification permissions and local-network firewall settings may affect alerts and discovery.

Offline delivery requires both apps to be reachable together. Pending files must remain available on the sender's device. Backup/restore and application-level history encryption are currently Windows features.

The Windows installer is unsigned. The Android APK is signed with LANCOM's dedicated release key. SHA-256 checksums are included with the downloads.
